# v0.4.1 human-assisted regression examples

These examples demonstrate the validated v0.4.1 data model, Final template, physical-page evidence links, paper-type profiles and visual-selection gates.

They are **not autonomous outputs**. Their frontmatter records:

```yaml
review_status: reviewed
generation_mode: human_assisted_regression
autonomous_generation: false
```

Autonomous multi-pass Evidence/Claim generation is a v0.5 objective.

The `zotero://` links contain attachment keys from the private validation library and are preserved only to demonstrate link shape. They are not expected to open in another Zotero library.

Paper figures in `assets/` are source excerpts for evaluation and documentation. They are not covered by LitAnchor's AGPL license; see `assets/README.md`.
