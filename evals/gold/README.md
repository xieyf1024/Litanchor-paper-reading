# Gold annotations

Store independently human-reviewed gold annotations here. Include only the minimal evidence excerpts needed to verify a claim, with one-based physical PDF pages, numbers/units/conditions and epistemic labels.

An empty reading template defines fields but is not a gold answer. An AI-generated or AI-assisted reference note defines useful coverage candidates but is also not gold, because using it directly would score the system against its own output. Follow `AI_ASSISTED_REFERENCE_GUIDE.md` before promoting any item.

At least two papers should be independently annotated by two reviewers before disagreement resolution. Keep hidden-test annotations, copyrighted PDFs and private research materials outside the public repository.
