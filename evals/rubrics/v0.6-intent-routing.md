# v0.6 semantic intent-routing rubric

This regression set evaluates an Agent-facing contract, not a literal command
parser. The utterances in `../cases/v0.6-intent-regression.json` are examples
to be presented as user messages during an Agent evaluation. They must not be
copied into production regular expressions, keyword tables or exact-string
branches.

For each case, record:

- inferred lifecycle or single-paper intent;
- whether the Agent proceeds or asks one necessary clarification;
- paper selector when applicable;
- configured/default versus explicit/re-authorized Vault handling;
- whether the requested support bundle or preservation behavior is retained.

A case passes when the structured decision matches `expected` without silently
changing the paper, permission scope or write destination. Paraphrase at least
one utterance per intent before each release to make sure the result is based on
meaning rather than memorized wording.

Release gate: every lifecycle intent is represented, Chinese/English/mixed
requests are represented, all five paper-reference forms are represented, and
all ambiguity cases cause clarification instead of guessing.
