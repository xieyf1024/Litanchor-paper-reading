## Narrow generic fixes after inspection

Four paper-independent defects were corrected without changing the frozen note
contract or adding paper-specific answers:

1. Rendering no longer duplicates an existing provenance marker such as
   `[分析] [分析]`.
2. The range-symbol gate now accepts an unchanged `±` only when a receipt
   records that the exact symbol was verified on an original PyMuPDF page
   render. Corrected symbols and unchanged verified symbols remain distinct
   states.
3. Figure crops can bind a caption range to a separate original-PDF plate page;
   the image still comes from the physical plate page and ambiguous bindings
   remain blocked.
4. A direct local-PDF run plan can target a new standalone Markdown file
   without requiring Zotero or Obsidian configuration.

The direct route was also exercised against the 38-page unseen PDF: it resolved
`source_type=user_pdf`, required neither integration, and prepared all 38
physical pages through the same PyMuPDF baseline. The semantic candidate above
uses that same post-acquisition workflow.

The second fix was required after original-page inspection confirmed that
`0.52 ± 0.95 °C` and `1.36 ± 0.84 °C` were printed as uncertainties rather
than OCR-corrupted ranges.

## Remaining RC gates

The operational lifecycle passed in three isolated application profiles inside
one Windows user context:

- English path with a real venv and core dependency installation;
- non-ASCII user/Vault paths with spaces;
- interrupted activation followed by repair.

All three passed install, setup, direct-PDF run-plan, upgrade, rollback and
uninstall while preserving configuration and Vault contents. Temporary data
was removed. The machine-readable report is
`v1.0.0-rc1-clean-profile-smoke.json`. This validates lifecycle and path
isolation; it is not presented as independent-user usability evidence.

Content and template work stays frozen unless a release-blocking defect is
found. The final unseen note is user-approved. The exact candidate commit must
still pass CI, privacy, anti-leak, packaging and release checks before tagging.
