# v0.6 Public Beta stabilization checklist

This phase stabilizes the released `v0.6.0-beta.1` workflow. It does not add a
new paper-reading mode and does not change the frozen v0.6 paper set.

## Current scope

- [x] Split public feedback into installation/lifecycle, runtime/PDF and note-quality forms.
- [x] Add an allowlist-based `doctor --support-bundle` ZIP that excludes paper content, identifiers, credentials and local paths.
- [x] Add Chinese, English and mixed-language semantic intent cases for all lifecycle operations and one-paper selectors.
- [x] Add regression coverage for interrupted activation, configuration preservation and Vault non-interference.
- [x] Add a release-time Skill compaction check for entry size, duplicate long rules and missing referenced resources.
- [x] Run the complete 158-test repository suite, Skill validation, compilation, link check, privacy/anti-leak audit and release build locally.
- [x] Run the Windows lifecycle smoke path with a real isolated install, live Zotero Local API probe and redacted support bundle; preserve the synthetic Vault sentinel and remove the temporary environment afterward.
- [ ] Push the branch and require the complete GitHub Actions matrix on the exact candidate commit.

## Freeze boundary

- No test-paper title, result, number, figure, page or paper-specific branch may enter the distributable Skill.
- The v0.6 frozen paper manifests and their evaluation status are unchanged.
- MinerU remains consent-aware structure enhancement; PyMuPDF remains evidence authority.
- No Zotero write-back, batch reading, multi-paper review, vector database or autonomous Skill publication is added here.

## Version decision

Public-beta stabilization uncovered and fixed a reproducible lifecycle defect:
repair did not remove a stale activation backup after the active Skill had
already been restored, so later activation could remain blocked. This branch
therefore qualifies for `v0.6.0-beta.2` after exact-commit CI passes. After that
patch release, freeze the rules and proceed to the clean-profile
`v1.0.0-rc1` qualification described in `ROADMAP.md`.
