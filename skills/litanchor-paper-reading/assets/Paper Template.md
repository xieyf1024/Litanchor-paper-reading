## 1. 论文速览

> [!abstract] 一句话概括
> 研究问题、核心方法、主要结论或贡献。

| 项目 | 内容 |
| :--- | :--- |
| 论文类型 | 实证研究 / 方法或算法 / 模型说明 / 综述；必要时补充 benchmark、dataset、system 等特征 |
| 标题判断 | 研究对象、研究问题、研究方法 |
| 摘要四要素 | 目的、方法、结果、结论 |
| 研究背景与缺口 | 为什么研究；已有工作还缺什么 |
| 研究对象 / 数据 / 模型 | 研究了谁或什么；使用什么数据、材料或模型 |
| 核心研究问题 | 作者最终要回答、检验或构建什么 |
| 方法路线 | 输入 → 关键步骤 → 评价或验证方式 → 输出 |
| 主要发现 | 2—4 条最重要发现、比较或综合判断；保留关键数值、条件和原文位置 |
| 核心贡献 | 相对已有工作真正新增了什么 |
| 结论与适用边界 | 最强可支持结论；适用于什么范围；不能推出什么 |
| 关键限制 | 最影响结论解释或迁移的限制 |
| 文章结构与论证主线 | 背景与缺口 → 研究问题 → 方法与证据 → 结果与解释 → 结论与边界 |
| 关键图表与回看位置 | 最值得查看的 1—3 个图表、章节及页码 |
| [分析] 精读建议 | 值得精读 / 按需精读 / 暂不优先；给出与阅读目标相关的理由 |
